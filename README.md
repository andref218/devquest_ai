# DevQuest AI

An AI-powered multi-agent system that generates personalized project-based learning paths for developers.

## Overview

DevQuest AI explores the design and implementation of multi-agent AI systems using Large Language Models (LLMs).

Given a learning goal, multiple specialized AI agents collaborate to:

- Understand the user's learning objective.
- Generate a personalized learning path.
- Create practical project-based coding challenges.
- Review completed projects and provide feedback.

The primary goal of this project is to demonstrate multi-agent orchestration and modern AI application architecture.
